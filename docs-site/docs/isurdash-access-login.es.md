# 6.1. Primeros Pasos: Acceso e Inicio de Sesión

El acceso a la plataforma IsurDASH se realiza a través de un navegador web estándar. El proceso de alta se inicia mediante una invitación por email, para garantizar la seguridad de la cuenta.

## Proceso de Creación de Cuenta

1.  **Creación de la cuenta:** para obtener acceso, el usuario debe primero facilitar una dirección de email válida al equipo de Isurki. A esta dirección se le enviará un correo con un enlace de invitación a la plataforma.
2.  **Establecer contraseña:** el usuario debe pulsar el enlace recibido en el correo de invitación. Será redirigido a una página segura de IsurDASH donde podrá establecer su contraseña personal.
3.  **Inicio de sesión:** una vez establecida la contraseña, el usuario puede acceder a la plataforma en cualquier momento desde la siguiente dirección:

    * **URL de acceso:** [https://isurdash.isurki.com/login](https://isurdash.isurki.com/login)

    El inicio de sesión es un proceso de dos pasos: primero se introduce la dirección de email y se pulsa **Login**, y después se introduce la contraseña en la pantalla siguiente y se vuelve a pulsar **Login**.

![Pantalla de inicio de sesión de IsurDASH](images/7-login.png){width="700"}

*La pantalla de inicio de sesión de IsurDASH.*

!!! note "Nota"
    La opción "**Forgot password?**" no aparece en el formulario de inicio de sesión inicial — solo se muestra tras un intento de contraseña incorrecto. Desde ahí puede usarse para recuperar el acceso. Para cualquier otro problema de acceso, contactar con el equipo de soporte de Isurki.
